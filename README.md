# 智能硬件行业及消费者分析

一个纯前端数据可视化网页，聚焦智能硬件行业市场洞察与消费者研究。

## 功能模块

| 模块 | 内容 |
|------|------|
| **市场概览** | 关键指标卡片（规模、增速、用户数、复购率）+ 历年市场规模柱状图 |
| **品类分析** | 五大品类（穿戴、家居、娱乐、健康、车载）的市场占比与产品明细 |
| **消费者画像** | 年龄分布环形图、购买决策因素排行、消费者分层卡片、渠道偏好矩阵 |
| **发展趋势** | 2025–2028 年行业时间轴，涵盖 AI 端侧推理、全屋互联、健康监测、空间计算等方向 |

## 技术栈

- **HTML5** — 语义化结构
- **CSS3** — CSS 变量、Grid / Flexbox 布局、渐变、过渡动画
- **Vanilla JS** — IntersectionObserver 驱动的入场动画、数字滚动、进度条、回到顶部
